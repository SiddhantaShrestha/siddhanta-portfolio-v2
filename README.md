# Siddhanta Portfolio V2

New portfolio for Siddhanta Shrestha. The live site at [siddhantashrestha.com.np](https://siddhantashrestha.com.np/) and the [SiddhantaPortfolio](https://github.com/SiddhantaShrestha/SiddhantaPortfolio) repository are separate and untouched.

## Scripts

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
npm run format
```

Copy `.env.example` to `.env.local` when you need a public site URL other than `http://localhost:3000`.

## Current scope

Phases 1 and 2:

- Next.js App Router, TypeScript, Tailwind CSS, linting, formatting
- Premium dark UI with hero, workstation poster stage, projects, lab, skills, about, contact
- Stub case study routes at `/projects/[slug]`
- 3D packages installed and restricted to `src/experience`, with no WebGL canvas loaded yet
